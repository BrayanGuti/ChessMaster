# Security policy

## Supported versions

Only the latest version published on npm of [`@brayanguti/react-chessmaster`](https://www.npmjs.com/package/@brayanguti/react-chessmaster) receives security fixes. If you are on an older version, upgrade first and check whether the problem persists.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Report it privately through GitHub:

1. Go to the [Security tab](https://github.com/BrayanGuti/ChessMaster/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem: what is affected (the package, the site), the steps to reproduce it, and its impact.

The report stays private between you and the maintainer.
